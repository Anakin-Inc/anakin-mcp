# CrewAI tools — submission instructions

Real, PR-buildable path — confirmed via `crewAIInc/crewAI/lib/crewai-tools`
(consolidated from the previously separate `crewAIInc/crewAI-tools` repo,
archived 2025-11-10). Direct precedent already merged: Firecrawl, Tavily,
Exa, Serper, Brave — all comparable web-scraping/search APIs.

## What's here

```
anakin_scrape_tool/anakin_scrape_tool.py    wraps anakin-sdk's client.scrape()
anakin_scrape_tool/README.md
anakin_search_tool/anakin_search_tool.py    wraps anakin-sdk's client.search()
anakin_search_tool/README.md
```

Both wrap the official `anakin-sdk` Python client directly (same "reuse the
SDK, don't reimplement HTTP" choice made for `langchain-anakin` earlier this
session) — mirrors `FirecrawlScrapeWebsiteTool`'s exact pattern of wrapping
`firecrawl-py`, pulled live from their real, current source via `gh api`.

## Verified, not assumed

- `python3 -m py_compile` passes on both files.
- `pip install crewai` hung with no output in this sandbox (same network
  restriction hit by `langchain-anakin` and the earlier LangChain package —
  confirmed `npm` works here, `pip` doesn't) — never got a live import/run.
- Every structural detail (the `BaseTool`/`EnvVar`/`PrivateAttr` pattern,
  the lazy-import-with-`click.confirm`-install fallback, `package_dependencies`,
  `model_rebuild()` at module load) copied from the real, current
  `FirecrawlScrapeWebsiteTool` source, not guessed.
- Did **not** hand-edit `tool.specs.json` (the tools registry) — inspecting
  it showed it's clearly auto-generated from each tool's Pydantic schemas
  (full JSON Schema dumps, not hand-maintainable), so it needs to be
  regenerated by their build tooling, not edited directly.

## Steps (needs the account owner)

1. Fork `crewAIInc/crewAI`, add these two directories under
   `lib/crewai-tools/src/crewai_tools/tools/`.
2. Register both classes in
   `lib/crewai-tools/src/crewai_tools/tools/__init__.py` (import + `__all__`
   entry, same as the Firecrawl tools' entries there).
3. Run whatever generates `tool.specs.json` (not identified — check their
   build scripts/Makefile) rather than hand-editing it.
4. Add `anakin-sdk` as an optional dependency in `lib/crewai-tools/pyproject.toml`,
   matching how `firecrawl-py` is declared there.
5. Open a PR.
